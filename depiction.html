Sendspin Player

Version 1.0.0 · Multimedia

Compatible: iOS 3.0 — iOS 9.3.6 (ARMv7 / ARMv6)
★ Verified & tested on iPhone 4s (iOS 9.3.6)
Description

Native Sendspin & Music Assistant multi-room synchronized audio player with sub-millisecond clock synchronization, native DNS-SD / Bonjour discovery, Lock Screen metadata & Control Center remote events.

Features
  • Lock-Free SPSC Ring Buffer CoreAudio Engine
  • Native FLAC, Opus, and uncompressed PCM decoding
  • Automatic Bonjour server discovery with server memory
  • Interactive sync delay fine-calibration (±1ms, ±10ms)
  • Background keep-alive mode to prevent RAM purge
